# `comNG` 使用说明

`comNG` 是一款现代且功能强大的串口助手软件。基础的介绍和使用说明已经在 readme 提及了，这里主要阐述 `comNG` 使用过程中稍微复杂的部分，包括：

- [`comNGLang` 语法说明](./comNGLang-Syntax.md)，以约定的格式高亮你的串口日志。
- [`comNG` 里的高亮](./Highlight-in-comNG.md)，助力高效文本分析。
- [`comNG` 里的快捷键](./Shortcuts-in-comNG.md)，使用快捷键让你事半功倍。
- [`comNG` 里的其他高级功能](./Advances-in-comNG.md)，包含 Modem 信号控制、数据图像化消息格式等等。

`comNG` 使用的主要组件包括：

- [Electron](https://www.electronjs.org/)
- [Node SerialPort](https://serialport.io/)
- [monaco editor](https://www.lihaoyi.com/post/BuildyourownCommandLinewithANSIescapecodes.html)
- [Materialize](https://materializecss.com/)

没有这些强大的模块，`comNG` 做不出来，非常感谢相关作者和贡献者。
